# Exact 3.10 heat infrastructure screening proxies

Three independent ecoinvent 3.10 cut-off reviews qualify complete native UVEK
2026 infrastructure through the existing 2025 migration edge. The machine-readable
review is `brightpath/data/export/uvek_heat_310_infrastructure_review.json`.
It pins source market and producer inventories, both native references, unchanged
migration rules and explicit scientific limitations. Raw licensed inventories are
excluded from this repository.

The 10 kW oil boiler and 3000 litre tank use one physical unit, with matching
nominal capacities and documented twenty-year lifetimes. Complete native material,
manufacturing, transport and disposal inventories replace the source producer mix.
Internal material, paint reference basis, energy, waste allocation, geography,
vintage and uncertainty differences remain warnings. No additional operating fuel,
manufacturing, pipes, valves, packaging or disposal inventory is added.

The chimney uses one physical metre in both databases. Source documentation states
eighty years; native documentation states forty years and adds a steel liner in
2016. Source concrete versus native fireclay, geometry and lifetime differences are
explicit screening limitations. Signed metres remain unchanged: there is no
inferred lifetime, replacement or concrete-density multiplier. This does not claim
equivalent lifetime heat service.

No migration rule, recipe, shared review or native inventory changes in this batch.
Premise grants three exact-profile permissions with warnings, preserving all
previous fingerprints. Other source releases and system models receive no new
permission. Caller signs, quantities, formulas and supported uncertainty remain
unchanged. Native biosphere exclusions and unquantified score effects remain
limitations; finite LCI does not establish LCIA equivalence or impact completeness.

Verification covers signed normal/lognormal caller uncertainty, input ownership,
other-version refusals, cold/warm warning retention, isolated installed-wheel
migration and finite native supplier LCIs. Heat remains disabled in the public API
until its complete integration and export checks pass.
